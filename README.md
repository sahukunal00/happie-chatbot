Happie Chatbot
Developed by Kunal, Happie Chatbot leverages the Llama 3.2 model for dynamic, human-like interactions. It features secure login, math and coding help, and versatile Dialogflow intents.

Features
Dynamic Interaction: Engage in conversations with human-like responses.
Secure Authentication: Utilizes a robust email and password system for user authentication.
Math Solving: Solves complex mathematical problems upon request.
Coding Assistance: Helps users by answering coding-related queries.
Dialogflow Intents: Manages a wide range of intents for diverse conversational needs.
Installation
To get started with Happie Chatbot on your local machine, follow these steps:

Clone the repository:


git clone https://github.com/sahukunal00/happie-chatbot.git
cd happie-chatbot
Set up a Python virtual environment:


python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`
Install the required packages:


pip install -r requirements.txt
Usage
To run the Happie Chatbot, execute:


python app.py
Access the web interface at http://localhost:5000.
